# 💻 Assignment Problems

All coding solutions are implemented inside a single file:

```text
solutions.ts
```

## ✅ Problem List

### Problem 1 — Filter Even Numbers

Create a function `filterEvenNumbers` that returns only even numbers from an array.

### Problem 2 — Reverse String

Create a function `reverseString` that reverses a given string.

### Problem 3 — Type Checking with Union Types

Use a union type `StringOrNumber` and implement type guards using `checkType`.

### Problem 4 — Generic Function

Create a generic function `getProperty` to safely access object properties.

### Problem 5 — Interface & Object Manipulation

Define a `Book` interface and implement `toggleReadStatus`.

### Problem 6 — OOP with Inheritance

Create a `Person` class and extend it with a `Student` subclass.

### Problem 7 — Array Intersection

Create a function `getIntersection` that returns common elements from two arrays.
